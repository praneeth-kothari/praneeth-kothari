## 🔨 Selected work

### [Multi-Agent Test Orchestration Harness](https://github.com/praneeth-kothari/multi-agent-test-orchestration)

Hierarchical multi-agent workflow where an orchestrator agent decomposes a test requirement and delegates to role-specialised agents:

```
Requirement → Orchestrator → Requirement Analysis Agent (test cases)
                           → Code Agent (Playwright specs)
                           → Review Agent (QA standards)
                           → Healer Agent (failure triage)
```

Includes shared task context, tool bindings, an explicit review loop and deterministic replay for debugging.

### [Selenium E2E Automation Framework](https://github.com/praneeth-kothari/selenium-framework-github-actions)

Selenium WebDriver 4, Java 17, Cucumber BDD, JUnit 5, Allure reporting — 15 UI user journeys + 5 REST Assured API tests. Jenkins pipeline with Allure report, preflight setup checker, Page Object Model.
